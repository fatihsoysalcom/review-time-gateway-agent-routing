# Review Time Gateway Agent Routing

This example demonstrates a 'Review Time Gateway' system that routes review tasks to different types of agents (Free, Paid, Local) based on task priority and agent availability. It simulates how a gateway can optimize workflow by assigning high-priority tasks to faster, higher-quality agents, improving overall efficiency and quality in a review process.

## Language

`python`

## How to Run

1. Save the code as `review_gateway.py`.
2. Run from your terminal: `python review_gateway.py`
